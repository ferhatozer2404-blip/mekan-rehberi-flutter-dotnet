Mekan Rehberi Mobil Uygulaması

Bu proje, Flutter ile geliştirilmiş mobil/web ön yüzü ve ASP.NET Core Web API ile yazılmış arka yüz mimarisine sahip read-only bir mekan listeleme uygulamasıdır.

Kullanılan Teknolojiler

  Frontend: Flutter / Dart (Cross-Platform / Web)
  Backend: C# .NET Core Web API
  Database: MS SQL Server & Entity Framework Core
  Güvenlik: .NET Secret Manager (Connection String izolasyonu)
